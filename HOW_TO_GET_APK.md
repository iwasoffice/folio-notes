# Android APK

This environment cannot compile a signed Play Store APK (no Android SDK / keystore).

## Fastest way to get an APK from the live PWA

1. Open https://www.pwabuilder.com
2. Enter https://folio-notes-nine.vercel.app
3. Click **Package for stores**
4. Choose **Android**
5. Generate and download the package
6. Inside the download you will get a test APK

Install that APK on your phone (enable Install unknown apps for the browser/file manager).

## After GitHub + Vercel are linked

Repeat PWABuilder using your new production URL instead of folio-notes-nine.vercel.app.
